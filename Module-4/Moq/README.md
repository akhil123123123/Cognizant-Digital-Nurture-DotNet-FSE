# Moq

## Overview

Moq is a popular mocking framework used with NUnit for unit testing in .NET. It allows developers to create fake objects (mock objects) instead of using real dependencies. This helps in testing a class independently without depending on databases, APIs, or external services.

---

## Learning Objectives

After completing this module, I learned to:

- Understand the concept of mocking.
- Create mock objects using Moq.
- Test classes independently.
- Use dependency injection for better testing.
- Verify interactions between objects.
